# AIStata-for-StataMCP简介


AIStata-for-StataMCP ,简称  AIStata MCP，该扩展插件提供两种形态，扩展/插件+MCP的形态存在于VsCode等Ide，也可以接入MCP

目前，[AIStata  MCP适配主流AIAgent](https://mp.weixin.qq.com/s/qiQzZ6amy_hTi1SlVE6uqg)。

在计量经济网最新开发的一站式科研平台中，也介入了该MCP扩展插件，可以实现AI与Stata的交互!
